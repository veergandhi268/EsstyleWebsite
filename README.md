# ESSTYLE — Premium Custom Uniforms & Corporate Apparel

> **"Se Kharido, Style Se Paheno"**

Modern, responsive website for **ESSTYLE**, India's premier bespoke uniform manufacturer specializing in corporate apparel, healthcare scrubs, chef coats, industrial workwear, sports teamwear, and institutional attire.

---

## 🚀 Features

- **Modern Glassmorphic Dark Theme**: Curated obsidian/navy dark background with vibrant lime (`#8DC63F`) and cyan (`#38BDF8`) brand accents.
- **Dynamic Category Filtering**: Interactive tab switcher across 6 uniform sectors (Corporate, Healthcare, Hospitality, Industrial, Sports, Institutional).
- **Clientele & Social Proof**: Trusted by 180+ enterprises featuring an infinite animated client logo marquee and genuine customer reviews.
- **Advanced Technical Showcases**: Detailed sections for fabric engineering (Dri-Fit, 100% combed cotton, silver-ion shield) and 4 branding technologies (3D Tajima embroidery, HD DTF, dye-sublimation, screen printing).
- **Streamlined Contact Form**: Direct inquiry capture for bespoke corporate orders.
- **Mobile Responsive**: 100% fluid layouts with sticky header navigation across mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic, SEO-optimized markup with OpenGraph tags.
- **CSS3 (Vanilla)**: Custom design system with CSS variables, smooth transitions, and glassmorphism.
- **JavaScript (Vanilla)**: Lightweight, dependency-free interactive logic.
- **Font Awesome 6**: Modern vector iconography.

## 📦 Local Development

1. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   cd <your-repo-name>
   ```

2. Open with any local HTTP server (e.g. Python):
   ```bash
   python3 -m http.server 8090
   ```

3. Open `http://localhost:8090` in your web browser.

## 🌐 Deploy to Vercel

This repository is ready for zero-config static deployment on [Vercel](https://vercel.com/):

1. Push this repository to your GitHub account.
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Click **"Add New..."** > **"Project"** and import your GitHub repository.
4. Framework Preset: **Other** (Root directory: `./`).
5. Click **"Deploy"**.

Any future commits pushed to the `main` branch will automatically trigger a new deployment on Vercel.
